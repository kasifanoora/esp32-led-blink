# ESP32-C3 LED Blink
My first embedded systems project as an EEE student!

## Project Overview
A simple LED blinking project using an ESP32-C3, ESP-IDF, and FreeRTOS, tested in the Wokwi simulator.

## Components
- ESP32-C3
- LED
- Resistor
- Wokwi simulator

## What I Learned
- Configuring a GPIO pin as an output
- Controlling an LED using C
- Using FreeRTOS delays
- Exploring embedded systems through simulation

The source code is available in `main.c`.
